# sidekick-models

Model files that [Sidekick](https://github.com/royce-mathew/sidekick) downloads on demand. The app
pins each file's size and SHA-256 and checks both before use.

## Releases

- [`diarization-community-1`](https://github.com/royce-mathew/sidekick-models/releases/tag/diarization-community-1):
  [pyannote/speaker-diarization-community-1](https://huggingface.co/pyannote/speaker-diarization-community-1),
  converted to ONNX and used for Listen speaker labels. Licensed
